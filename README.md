## 確定仕様（ユーザー指示。企画書からの変更点を含む）
- 闘技場(arena)固定／ソロ／1フェーズ180秒／無限フェーズ／死亡で即終了／通常ギア無効（弾・ULT・戦術のみ可）
- **敵のフェーズ強化率は 1.3倍**（企画書の1.5倍から変更）。Bot HP = 基礎HP × 1.3^(p-1)（切り上げ）。Bot数は 3×p（種類は近/中/遠を各p体）
- **開始時、プレイヤーは闘技場の中央にスポーン**
- **Bot移動速度 = プレイヤー通常移動速度の 0.5倍**
- **各フェーズ開始前に5秒カウントダウン**（フェーズ1開始前も、ギア選択後の次フェーズ前も。カウント中はBot出現・攻撃・フェーズ時計は停止）
- Bot射程: 近(<=5m)重量弾／中(5〜10m)通常弾／遠(>=10m)狙撃弾。敵弾の着弾エフェクトは出さない
- スコア: 撃破ごとに +現在フェーズ番号（企画書の推奨案。未確認）

## サバイバル特製ギア（確定カタログ 全27種）
全て等確率。フェーズクリア後に「抽選対象」から3つ（重複なし）。
- 発展ギア（◯2,◯3）は1つ前を取得済みでないと抽選対象外
- 取得済みギアは抽選に出ない。**例外：背水の陣／苦肉の策／救急医療は何度でも出る**（背水・苦肉の再取得は乗算で重ねがけ＝実装方針、要確認）
| ID | 名称 | 効果 |
|---|---|---|
| rest1/2/3 | 休憩 | 立ち止まり中、HP+1/秒 → 回復量1.5 → 回復間隔0.8秒 |
| pierce1/2/3 | 貫通 | 通常弾が30%で貫通 → 50% → 貫通した弾の威力1.5倍 |
| hasty1/2/3 | 生き急ぎ | 与ダメ・被ダメ共に+50% → 被ダメ増加30% → 10% |
| head1/2/3 | ヘッドショット | 10%でクリティカル(2倍) → 倍率3倍 → 確率20% |
| mp1/2/3 | 超持続 | 弾が敵に当たるとMP+5 → +10 → +15 |
| vamp1/2/3 | 吸血 | 敵撃破でHP+5 → +10 → +15 |
| vital1/2/3 | 生命力 | 撃破時5%で最大HP+10(回復なし) → 10% → 15% |
| take1/2/3 | 道連れ | 撃破時、半径2m内の敵が10%で倒れる → 30% → 範囲半径4m |
| haisui | 背水の陣 | 最大HP×0.5、与ダメ×2 |
| kuniku | 苦肉の策 | 最大HP×1.5、与ダメ×0.5 |
| heal | 救急医療 | HP全回復 |
注: 「道連れ」で倒れた敵も撃破扱い（スコア・吸血・生命力は発動するが、道連れの連鎖は不可とする想定＝要確認）。

  - Bot 3種（近=重量弾/中=通常弾/遠=狙撃弾）。各フェーズ 各タイプ p体（合計3p）が**同時存在**し、撃破されたら同タイプを補充（U-01の推奨案）。HP=ceil(10×1.3^(p-1))
  - Bot速度 = 11×0.5 = 5.5。弾速・威力は既存 bulletMasterData / computeUnbuffedBulletDamage を再利用。敵弾は着弾エフェクトなし（独自配列で管理、`spells`とは分離）

  - フェーズクリア→Bot/敵弾全削除→ポインタロック解除→特製ギア3択→選択後に次フェーズのカウントダウン（二重選択防止あり）

### 解釈・仮決め（要確認）
1. 貫通3「威力1.5倍」＝**一度敵を貫通した後の同じ弾が次の敵に当たる時**に1.5倍（初撃は等倍）
2. 道連れ：連鎖しない（道連れで倒れた敵からは再発動しない）。道連れで倒れた敵も撃破扱い（スコア・吸血・生命力あり）
3. 背水の陣・苦肉の策は再取得で乗算を重ねる（例：背水×2回→HP1/4・与ダメ4倍）。最大HP変更時、現HPは据え置きで上限超過のみ切り詰め（苦肉でも回復しない）
4. 「立ち止まっている」＝XZ移動が0.02/フレーム以下（ジャンプ中でも移動していなければ回復）
5. ヘッドショット：弾ごと独立抽選、生き急ぎ・背水等の倍率の後に乗算
6. フェーズ1 Bot HP=10（全弾種ワンパン可）。Bot射撃間隔 近2.2s/中1.5s/遠3.0s（要調整）
